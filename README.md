# 任务文件清单 Skill

让 AI 助手在一项任务结束时交代清楚：动过哪些文件、占多大、哪些还要保留。可以盘点整项任务、其中一个步骤，或一批已有文件。

- **核对变动**：区分新增、改写、移动、删除和只读引用。必要时用前后快照、回执和哈希核对，同一硬链接实体只计一次。
- **汇总结果**：按原始文件、原始数据、过程文件、结果文件、结果数据五类，列出数量、大小和保留状态。需要追溯时，可查看逐项底账。
- **标记待核**：证据不足时如实标明。
- **清理过程文件**：整理完成后，获得授权即可清理本次任务生成且已确认无用的过程文件。

## 安装和使用

将三个 Skill 放进助手的同一个 Skill 目录：

| Skill | 仓库来源 | 安装位置 |
| --- | --- | --- |
| 任务文件清单 | 根目录 [SKILL.md](./SKILL.md) | `task-file-inventory/SKILL.md` |
| 整理 | 整个 [task-file-organizer](./task-file-organizer) 目录 | `task-file-organizer/` |
| 垃圾桶 | 整个 [trash-bin](./trash-bin) 目录 | `trash-bin/` |

整理负责文件归位和保留判断，垃圾桶负责经授权的可恢复搬移和恢复，任务文件清单负责汇总处理量和剩余量。垃圾桶附带的命令行脚本适用于 Windows，目录指纹工具需要 Python。

安装后可以这样提问：

> 盘点这次任务的文件，按五类汇总数量、大小和保留状态。

如果只想核对一个步骤，例如 PDF 导出，可以直接指定步骤。Skill 会把原稿准备和旁路验证排除在该步骤的统计之外。

## 输出示例

假设一次讲义制作核对了原稿，交付了 Word 和 PDF，并生成了一份结构化索引。下表是虚构示例。

| 类别 | 数量 | 大小 | 保留状态 |
| --- | ---: | ---: | --- |
| 原始文件 | 核对 1 份 | 1.20 MB | 保留 |
| 原始数据 | 0 | 0 | 0 |
| 过程文件 | 新增 2 个 | 86.00 KB | 保留 1 个，待核 1 个 |
| 结果文件 | 新增 2 份 | 2.40 MB | 保留 |
| 结果数据 | 新增 1 个 | 4.00 KB | 保留 |
