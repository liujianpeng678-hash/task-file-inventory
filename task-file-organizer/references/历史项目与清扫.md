# 历史项目与清扫

按当前任务选用与文件、引用及正式入口有关的章节。

## 大型历史项目整理：结果反推与任务批处理（2026-11-18）

适用于已授权整理的历史项目或大任务目录；普通任务收尾仍限本轮。先解决结果与过程混放，不把分类扩大成逐文件来源考证。

1. **先固定保留范围。** 从当前正式清单、实际读写入口和已采用回执反推原始材料、源码、运行与构建依赖及必要追溯证据，另列个人数据和独立必要工具。复用仍有效的用途与引用索引，批量匹配精确路径、文件身份和生成清单，先排除保留项、在途写入和已核同版本路径。原始输入即使尚未采用也保留。内容相同只能作为比对线索，正式采用、必要性和退役资格各用对应证据决定。
2. **按任务或产物集合分组。** 用任务清单、实际生产规则和消费者把路径分成保留、可处理过程、混合、待核。先从现有分类索引中选有明确清单字段、实际引用边或生成输出规则的批次；目录名、后缀和同格式记录只用于缩小范围。已有整组证据且目录成员、版本和引用安全均吻合时，直接生成精确批次清单，交现有工具预览；只读混放、未知和依赖冲突中能改变决定的文件正文。任务结束、目录名和未见引用各自只提供线索；清单覆盖不到的新增项及版本不符项原位保护。
3. **分类、归位、退役分开。** 已有生成规则和用途证据足以判断过程角色时，不要求逐份重建、逐像素比对或重验数学。独有原文、原始素材、必要恢复输入仍保护；按已授权范围选择过程归位或垃圾退役。整目录同盘原生搬移只在满足[垃圾桶 Skill 的整目录边界](../../trash-bin/SKILL.md#已确认整体弃用目录的快速清理2026-11-04)时使用；否则复用精确子项清单，不凭提效扩大删除权限。旧入口兼容须单独核验，消费者拒绝链接时保留受影响项。
   - **用待核路径和证据覆盖选择下一批。** 从原用途索引筛出所选范围的待核路径，一次读取对应正式回执、生产清单或恢复清单，按精确路径或清单声明的文件身份关联。优先处理证据能覆盖一组路径、且能明确用途或安全归位的批次。同一来源与版本的证据索引可跨批复用，按各路径的在用、引用、源内容与恢复用途分别判定。内容地址、哈希和硬链接只用于核对版本与实体。确认某路径承担源文件或恢复入口时，即使同实体还有其他入口，也保护已确认的入口。每组记录已核用途、实际归位及未覆盖路径，后续只接新增证据或版本变化。
   - **同任务的分阶段产物一次核查。** 正式回读能确认已闭批时，从同一任务的正式回执和它关联的初审、修订、补渲染、定稿等生成清单同时提取输出。先按各清单实际结构归一为“产物路径、完整内容哈希、阶段、来源清单”，合并同路径同版本并保留证据，过滤已处理项，再对候选核对现存版本。检查报告有多个载体列表时，一并抽取已核实语义的字段。仅当清单覆盖不足且有明确证据入口时补查该组。版本不符、多版本冲突无法解释、在途或正式引用项留置；历史阶段状态只用于判断当时用途，正式采用和退役资格各用自己的证据。
   - **同批同正文只判断一次。** 清单只覆盖部分版本时，从当前结果的实际引用、生产规则及其关联回执锁定候选组，再用完整内容 SHA-256 在同一已核产物语义内复用正文解析和角色判断。每条路径仍单独核对当前文件身份、引用、在用状态和源内容保护；同样的正文出现在正式入口、源资料或仍在写入的路径时，按该路径的证据单独处理。源内容随报告混存时保留并标记。仅对身份、保留规则及运行引用均已核清的纯过程项生成归位清单。遇到不匹配的结构或版本只补查该组有明确证据的变体，其余登记待核。
   - **闭批同版快照按发布回执成组。** 从回执提取同一事务、精确发布目标路径和完整的发布后 SHA-256，匹配组内各路径的现存版本，并核对该批已完成发布和回读。拟归位副本前，把独立原位保留的同版文件、发布回执及闭批依据列进保护清单，检查正式引用、恢复用途和在用状态。用文件身份确认保留件独立于待归位件，旧路径兼容硬链接不能充当独立保留件。缺正式路径、版本、闭批或独立保留证据时，只登记已证实的用途并原位保护。旧版本可能同时承载题源映射或恢复信息，保留其用途标记及可回读版本。
4. **每组一次计划、一次执行、一次验收与登记。** 同类产物复用已有通用程序、规则和参数，不因后缀或小格式差异反复新建整套脚本。将同批已核用途合并登记到现有索引/数据库，按批更新摘要，避免逐文件重写大清单。统计分别列用途覆盖、实际归位、兼容入口及留置量；部分批次完成不等于全项目完成。
5. **只验证本次实际风险。** 内容SHA及身份基线须来源可靠且前提未变才能复用；必要时补查新增/变化项。只为原位保留原件而读取元数据时，明确未读正文/未核SHA；读取可能阻塞时沿用可终止、有超时的读取机制。验收覆盖受影响成果、原件和依赖；整目录元数据指纹不能冒充内容SHA，也不重复运行前提未变的全库业务检查。
6. **调查止于可执行决定。** 预先确定本组所需证据和材料范围。先用精确任务、产物声明字段或引用目标筛出有限候选，确定哪些命中能改变分类或归位决定，再读取正文。命中即推进已授权批次。达到预定范围仍无有效命中时，在原核查记录留下已查任务或候选路径清单、对应证据的版本或处理水位、缺失条件和重开条件，然后转下一组。先由程序从待核项中选出有新增回执、引用、生成规则或文件版本变化的批次，再核受影响路径。用途库的全局更新时间及无关批次登记不触发重扫。同一组只补查变化部分；证据无法定位变化范围时，先核受影响清单，无法确定的路径继续待核。


## 清扫标记联动（2026-11-16）

清扫时按[垃圾桶 Skill 的逐路径标记规则](../../trash-bin/SKILL.md#清扫时逐路径标记2026-11-16-用户确认)先按八种用途种类标记文件/文件夹，混合文件夹标“混合”并细分已核查子项，再分别记录处理状态与检查覆盖；“已归堆”等状态不能代替种类。复用同一清单；已归堆不等于已释放空间，部分子项完成不等于整个目录完成。

已知为预览、检查或中间输出时，按垃圾桶 Skill 新增的“过程文件”类别登记，采用状态、在用情况和退役资格分别记录；它们未知不等于用途未知，也不授权归堆。真实原始资料及消费者必需媒体仍按源文件或必要依赖保护。此区分已在第5—7期88文件实际分类与SHA/身份核验中验证，未扩展到未知目录。
